# Convy — PWS Website Redesign

A premium, responsive React + Vite landing page concept for Convy.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Cloudflare Pages

1. Push this project to a GitHub repository.
2. In Cloudflare Pages, connect the repository.
3. Build command: `npm run build`
4. Build output directory: `dist`
5. Framework preset: Vite (or None).

## Included

- React + Vite
- GSAP + ScrollTrigger reveal animations
- Lenis smooth scrolling
- Responsive mobile navigation
- Interactive FAQ accordion
- Product UI mockups built in CSS/React
- Original CTA destinations linked to app.convy.info and convy.info

## Before client handoff

- Confirm the official logo files, brand colors and typography with Convy.
- Confirm the preferred demo/contact destination and any sales email or calendar URL.
- Obtain client approval for final copy, feature status and pricing wording.
- Replace illustrative dashboard data with approved product screenshots if supplied.
- Test all links, mobile breakpoints, keyboard navigation and reduced-motion behavior.
